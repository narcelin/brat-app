what makes this installable

  • manifest.webmanifest — name, icons, display: standalone. This is what strips Safari's UI.
  • sw.js — a service worker that pre-caches the shell so it opens offline.
  • apple-touch-icon — iOS uses this for the home screen icon, not the manifest icons.
  • viewport-fit=cover + env(safe-area-inset-*) — keeps content clear of the notch.
